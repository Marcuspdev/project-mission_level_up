JAVASCRIPT ES6: ARROW FUNCTIONS (=>)

Com o lançamento da atualização ES6 (ECMAScript 2015), o JavaScript ganhou diversas melhorias sintáticas e funcionais. Uma das adições mais importantes e utilizadas até hoje foi a Arrow Function (função flecha), que trouxe uma forma mais concisa e elegante de declarar funções na linguagem.

1. Sintaxe Tradicional vs. Arrow Function

Nas versões mais antigas do JavaScript, para declararmos uma função, obrigatoriamente utilizávamos a palavra-chave function. Com a sintaxe de flecha (=>), o código fica consideravelmente mais enxuto.

Observe a comparação direta entre as duas abordagens declarando uma mesma lógica de cálculo: 

// 1. SINTAXE TRADICIONAL (Antiga)
function calcularDano(base, bonus) {
    return base + bonus;
}

// 2. ARROW FUNCTION (Moderna)
const calcularDano = (base, bonus) => {
    return base + bonus;
};

2. Retorno Implícito (Implicit Return)

Uma das características mais poderosas das Arrow Functions é o retorno implícito. Quando o corpo da função possui apenas uma única instrução/expressão, podemos omitir as chaves {} e a instrução return. O JavaScript entende automaticamente que o resultado daquela linha deve ser retornado. 

// Função de linha única com retorno implícito
const dobrar = numero => numero * 2;

console.log(dobrar(5)); // Retorna 10

3. Escopo do 'this' Léxico

Além da economia de linhas, existe uma diferença funcional crítica: Arrow Functions não possuem seu próprio contexto de this. Elas herdam o this do escopo onde foram criadas (escopo léxico).

Em funções tradicionais, o valor de this muda dependendo de quem chamou a função (ex: um botão no DOM). Já em Arrow Functions, o this permanece fixo e atrelado ao escopo pai, o que evita bugs em callbacks e temporizadores.

4. Quando NÃO Usar Arrow Functions

  • Métodos de Objetos: Como a arrow function não tem seu próprio this, ela não conseguirá acessar as propriedades do próprio objeto via this.propriedade.
  • Constructors / Protótipos: Arrow Functions não podem ser chamadas com o operador new.
