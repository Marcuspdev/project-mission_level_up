LAYOUT CSS: FLEXBOX

Antes do surgimento do Flexbox (Flexible Box Layout Module), alinhar elementos lado a lado ou centralizar um bloco verticalmente no CSS exigia o uso de "hacks" complexos, como tabelas, float e posicionamento absoluto. O Flexbox foi criado especificamente para resolver esses problemas de alinhamento unidimensional (em linha ou em coluna) de forma simples e responsiva.

1. A Relação Container vs. Itens

O conceito fundamental do Flexbox baseia-se na relação entre o elemento pai (chamado de Flex Container) e seus elementos filhos diretos (chamados de Flex Items).

Para ativar o Flexbox, aplicamos a propriedade display: flex; no elemento pai. A partir desse instante, todos os seus filhos diretos passam a obedecer às regras do modelo flexível.

2. Os Dois Eixos do Flexbox

Diferente de outros modelos do CSS, o Flexbox trabalha com dois eixos ortogonais:

  • Eixo Principal (Main Axis): É o eixo primário ao longo do qual os itens flexíveis são dispostos. Por padrão, ele corre na horizontal (da esquerda para a direita).
  • Eixo Cruzado (Cross Axis): É o eixo perpendicular ao eixo principal. Por padrão, corre na vertical (de cima para baixo).

A propriedade flex-direction permite alterar a direção do eixo principal. Se usarmos flex-direction: column;, o eixo principal passa a ser vertical.

3. Alinhamento no Eixo Principal com justify-content

A propriedade justify-content define como o espaço livre restante no container será distribuído entre os itens flexíveis ao longo do eixo principal. Os valores mais comuns são:

  • flex-start: Empurra todos os itens para o início do container (padrão).
  • center: Centraliza todos os itens no meio do container.
  • flex-end: Empurra todos os itens para o final do container.
  • space-between: Distribui os itens uniformemente, colando o primeiro no início e o último no fim.
  • space-around: Distribui os itens com espaçamentos iguais ao redor de cada um.

4. Alinhamento no Eixo Cruzado com align-items

Enquanto o justify-content cuida do eixo principal, a propriedade align-items controla o alinhamento dos itens no eixo cruzado. Ela aceita valores como center (centraliza verticalmente), flex-start (alinha no topo) e stretch (estica os itens para preencher a altura).

5. Código Exemplo

Veja como centralizar perfeitamente um elemento no centro exato da tela utilizando apenas três linhas de Flexbox no container pai:

/* Container Pai */
.painel-central {
    display: flex;
    justify-content: center; /* Centraliza no eixo horizontal */
    align-items: center;     /* Centraliza no eixo vertical */
    min-height: 200px;
    border: 2px solid #ff0033;
    background-color: #000000;
}

/* Itens Filhos */
.item-painel {
    background-color: #1a0005;
    color: #ffffff;
    padding: 15px 25px;
    border: 1px solid #ff0033;
}
