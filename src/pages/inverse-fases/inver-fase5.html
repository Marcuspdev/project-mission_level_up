ARRAYS & O MÉTODO FOREACH()

Em JavaScript, um **Array** é uma estrutura de dados utilizada para armazenar uma coleção ordenada de valores (como números, textos, objetos ou até outros arrays) sob o nome de uma única variável. Saber iterar (percorrer) e manipular listas de dados é uma das habilidades mais vitais no desenvolvimento de software.

1. Do Loop 'for' Tradicional ao forEach()

Historicamente, para percorrer os itens de um array, utilizávamos o laço de repetição for tradicional com uma variável de controle de índice (let i = 0).

Embora o for ainda seja válido, o JavaScript moderno oferece métodos de alta ordem (Higher-Order Functions) integrados aos arrays, como o .forEach(), que tornam o código muito mais legível e declarativo.

2. Como Funciona o forEach()

O método .forEach() executa uma função de callback fornecida uma vez para cada elemento presente no array, em ordem ascendente do índice.

A função de callback passada para o forEach() aceita até três parâmetros:

  • elemento (obrigatório): O item atual do array sendo processado na iteração.
  • índice (opcional): A posição numérica do item no array (começando em 0).
  • array completo (opcional): A referência ao próprio array que está sendo percorrido.

3. Exemplo Prático de Código

Veja como é limpo percorrer uma lista de equipamentos do Mundo Invertido combinando forEach() e Arrow Function:

const inventario = ['Lanterna', 'Rádio Woki-Toki', 'Bússola', 'Mochila'];

// Percorrendo o Array com forEach
inventario.forEach((item, indice) => {
    console.log(`Equipamento #${indice + 1}: ${item}`);
});

4. Diferença Crucial: forEach() vs. map()

É muito comum confundir o forEach() com o método map(). Lembre-se desta regra fundamental:

  • forEach(): É usado para executar efeitos colaterais (como imprimir no console, alterar o DOM ou salvar dados). Ele **não retorna nada** (retorna undefined).
  • map(): É usado para **transformar** dados. Ele processa a lista e **retorna um novo array** de mesmo tamanho contendo os resultados modificados.
