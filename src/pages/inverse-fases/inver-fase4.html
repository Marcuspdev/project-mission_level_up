DOM & A API CLASSLIST

O DOM (Document Object Model) é a interface de programação que representa a estrutura de um documento HTML como uma árvore de objetos. Através do JavaScript, podemos selecionar elementos dessa árvore e modificar suas propriedades, textos e estilos em tempo real para responder às ações do usuário.

1. A Má Prática de Alterar Estilos Diretos

Muitos iniciantes tendem a alterar o visual de um elemento modificando a propriedade element.style via JS (ex: elemento.style.color = "red"). Embora funcione, essa prática insere estilos no-line no HTML, o que dificulta a manutenção e fere a boa prática da separação de responsabilidades (HTML para estrutura, CSS para estilo e JS para comportamento).

2. A Solução Limpa: O Objeto classList

A forma mais limpa e profissional de alterar a aparência de um elemento é definir as classes de estilo no arquivo CSS e usar o JavaScript para **adicionar** ou **remover** essas classes dinamicamente. Para isso, utilizamos a propriedade classList.

Principais métodos do classList:

  • classList.add('nome-da-classe'): Adiciona uma ou mais classes ao elemento.
  • classList.remove('nome-da-classe'): Remove uma classe do elemento.
  • classList.toggle('nome-da-classe'): Alterna a classe: se ela já existir, é removida; se não existir, é adicionada.
  • classList.contains('nome-da-classe'): Retorna um valor booleano (true ou false) indicando se o elemento possui aquela classe.

3. Exemplo Prático de Código

Veja como é simples alternar o tema ou o estado de um alerta no clique de um botão usando toggle:

// 1. Seleciona os elementos do DOM
const botaoAlerta = document.querySelector('#btn-alerta');
const caixaMensagem = document.querySelector('.caixa-mensagem');

// 2. Adiciona o ouvinte de evento (Event Listener)
botaoAlerta.addEventListener('click', () => {
    // Alterna a classe 'alerta-ativo' no elemento
    caixaMensagem.classList.toggle('alerta-ativo');
});
