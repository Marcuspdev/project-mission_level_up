JAVASCRIPT: VARIÁVEIS LET E CONST

O JavaScript é a linguagem de programação que confere comportamento e lógica às páginas web. O primeiro conceito fundamental do JS é a criação de **variáveis**, que funcionam como "caixas" na memória para armazenar dados.

1. Declarando Variáveis: let vs. const

No JavaScript moderno (ES6+), evitamos o uso da palavra-chave antiga var e utilizamos:

  • let: Utilizada quando o valor armazenado precisa de ser alterado posteriormente ao longo do programa.
  • const: Utilizada para declarar constantes, ou seja, valores fixos que não podem ser reatribuídos.
// 1. Variável Reatribuível (let)
let pontuacao = 0;
pontuacao = 10; // Permitido!

// 2. Constante Fixa (const)
const nomeJogador = "Alice";
// nomeJogador = "Bob"; // Erro! Constantes não mudam.

2. Exibindo Dados no Console

Para inspecionar e testar valores durante o desenvolvimento, utilizamos a instrução console.log(), que exibe os dados nas Ferramentas do Desenvolvedor (F12) do navegador.
