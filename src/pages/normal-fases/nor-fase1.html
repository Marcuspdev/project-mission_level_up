ESTRUTURA BÁSICA & TAGS DE TEXTO

O HTML (HyperText Markup Language) é a linguagem de marcação fundamental da web. Ela não é uma linguagem de programação, mas sim uma estrutura usada para marcar e organizar conteúdos como parágrafos, cabeçalhos, imagens e tabelas num documento web.

1. Anatomia de um Documento HTML5

Todo o ficheiro HTML válido necessita de um esqueleto padrão. Sem esta estrutura, o navegador não consegue interpretar corretamente os elementos da página:

  • <!DOCTYPE html>: Declaração obrigatória que informa o navegador que o ficheiro utiliza o padrão moderno HTML5.
  • <html>: A tag raiz que envolve todo o conteúdo da página.
  • <head>: Contém metadados, títulos de separador e hiperligações para ficheiros CSS externos (não visíveis diretamente na página).
  • <body>: O corpo do documento. Todo o conteúdo visível ao utilizador fica inserido aqui.

2. Hierarquia de Títulos e Parágrafos

Para organizar a leitura de forma acessível, utilizam-se marcas de cabeçalho de <h1> a <h6>, onde o <h1> representa o título principal e o <h6> o subtítulo de menor importância. 

<!DOCTYPE html>
<html lang="pt-PT">
<head>
    <meta charset="UTF-8">
    <title>Minha Primeira Página</title>
</head>
<body>
    <h1>Título Principal</h1>
    <p>Este é um parágrafo contendo texto <strong>importante</strong> e <em>enfático</em>.</p>
</body>
</html>
