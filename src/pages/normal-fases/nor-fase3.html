O MODELO DE CAIXA (BOX MODEL)

No CSS, todos os elementos HTML são tratados internamente pelo navegador como caixas retangulares. O **Box Model** (Modelo de Caixa) define as regras que calculam o espaço total ocupado por esses elementos no ecrã.

1. As Camadas do Box Model

O Modelo de Caixa é composto por 4 camadas concêntricas, de dentro para fora:

  • Conteúdo (Content): A área onde o texto, imagem ou vídeo é exibido. Definido por width e height.
  • Acolchoamento (Padding): O espaço transparente interno localizado entre o conteúdo e a borda.
  • Borda (Border): A linha de contorno que envolve o padding e o conteúdo.
  • Margem (Margin): O espaço transparente externo usado para afastar o elemento de outros elementos vizinhos.
.caixa-exemplo {
    width: 200px;
    padding: 20px; /* Espaço interno */
    border: 3px solid #0066ff; /* Borda */
    margin: 15px; /* Espaço externo */
}

2. A Propriedade box-sizing: border-box

Por padrão, o tamanho total de um elemento é calculado somando width + padding + border. Para evitar que adicionar padding aumente o tamanho final da caixa, usamos a propriedade box-sizing: border-box;.
