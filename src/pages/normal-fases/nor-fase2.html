CSS: SELETORES, CORES & FONTS

Enquanto o HTML define a estrutura, o **CSS (Cascading Style Sheets)** é responsável pelo aspeto visual da aplicação. Com o CSS, controlamos cores, fontes, espaçamentos e a disposição geométrica dos elementos no ecrã.

1. Estrutura de uma Regra CSS

Uma regra CSS é composta por um seletor (que indica qual elemento HTML será estilizado) e um bloco de declarações entre chaves com propriedades e valores. 

/* Sintaxe Padrão */
seletor {
    propriedade: valor;
}

/* Exemplo Prático */
p {
    color: #0066ff; /* Cor do texto */
    background-color: #f0f4f8; /* Cor de fundo */
    font-family: Arial, sans-serif; /* Tipo de letra */
}

2. Seletores Básicos

  • Seletor de Tag: Aplica o estilo a todas as tags do mesmo tipo (ex: h1, p).
  • Seletor de Classe (.): Aplica o estilo a qualquer elemento que possua o atributo class="...". Reutilizável em múltiplos elementos.
  • Seletor de ID (#): Aplica o estilo a um elemento único que possua o atributo id="...".
